## Bachelor Thesis "Drone Motor Test Stand"

I 3D-design and print a test stand for a drone arm featuring two coaxially mounted motors.
A load cell captures thrust, torque and dedicated power meters track the electrical input to each motor.
A STM32 handles motor control, data acquisition and signal evaluation.
Results are streamed via UART over USB to a PC for visualization.

# Parts used
**Readytosky 45A 2-6S BlHeli_S**
**2xEmax Eco II 2004 1600KV**
**Strain gauge load cell, 2kg**
**HX711 24-bit A/D weight sensor**
**Adafruit INA260 High or Low Side Voltage, Current, Power Sensor**
**STM32 NUCLEO-G474RE**
**V-Charge Field 60**
**2800mAh 22V LIPO Battery**
